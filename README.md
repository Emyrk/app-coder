# Coder Home Assistant Apps

A Home Assistant app repository for running the [Coder](https://coder.com)
control plane.

| App               | Description                                              |
|-------------------|----------------------------------------------------------|
| [Coder](./coder/) | `coderd` with zero built-in provisioners and external Postgres |

## Install

1. In Home Assistant, go to **Settings** > **Apps** > **App store**.
1. Open the menu in the top right, select **Repositories**, and add
   `https://github.com/Emyrk/app-coder`.
1. Install the **Coder** app and follow its Documentation tab.
